# Volume-preserving triaxial ellipsoid family

三軸楕円体の停留点構造に関する**専用研究リポジトリ**です。既存の回転楕円体研究 `cotaxxxx/bg-spheroid-family` と分けて管理します。

> **研究状態（2026-11-21時点のJudge報告による）:** 層IVおよび一部の細い帯はA1で採用済み。主矩形の内陸全域の分類は**未了**です。A1は全領域・全証拠の完全独立検証を意味しません。

## 目的と対象

体積を保存する三軸楕円体を、参照球からの写像

$$
L=\operatorname{diag}(1,s,st),\qquad (s,t)\in R=[1,16/5]\times[1,6]
$$
で表します（相似な体積保存正規化の対応は各成果物で明記します）。

**目的:** 閉球内の停留点について、内部停留点と境界での**全勾配の内側トレースの零**を区別して、個数・位置・指数を分類すること。

回転楕円体族は2026-11-20にJudgeが完了と裁定していますが、その証拠・正式台帳は元リポジトリを参照し、ここへ無断移植しません。

## 四つの層

| 層 | 主張 | 状態 |
| --- | --- | --- |
| I | `W₃ = E₃/q₃ > 0`：赤道面以外に零がない。赤道近傍は `H₃₃` を扱う | 未了／V60で計算費用を較正中 |
| II | `C₁₂ > 0`：赤道円板で軸の零を分離 | 未了／V60で計算費用を較正中 |
| III | 軸上の根がそれぞれ一対であること | 全域では未着手 |
| IV | `h₁,h₂,b₁,b₂` の零曲線と交点構造 | V57：A1採用済み |

**層IV（V57）:** 四本の零曲線は単純なグラフで、三軸内部の交点は `Z₁ ∩ B₂` の一つ（数値位置は `s≈1.567, t≈2.297`）との報告。数値位置とA1の到達範囲は元の証拠で照合してください。

**条件付き構造定理（V56）:** 層I〜IIIが対象全域で成立すれば、層IVの曲線を使って停留点分類を決められる、という条件付きの枠組みです。前提の成立をこのREADMEで宣言するものではありません。

## 現在A1採用済みの部分範囲

- 明示帯：`1 < s ≤ 1 + 2⁻³⁹, 2 ≤ t ≤ 5`。内部の停留点個数は、tに従って `1→3→5→3→1`。短軸の対は指数1、中間軸の対は指数2。
- 球の近傍：`log(st) ≤ 10⁻⁵`。中心のみが非退化極小。
- 回転辺近傍：同様の個数規則が成立する近傍の存在が報告されているが、**幅の数値は未確定**。
- 付録Cの除外：中心近傍で `W₃>0.51`、赤道近傍で `C₁₂>0.016`、長軸の円筒に零がない。

これらは狭い範囲の結果です。**主矩形Rの全域分類済みという主張ではありません。**

## 現在の計算計画

- **V58:** 二次の包囲によって較正時の必要箱数がおよそ1/100になったとの報告。
- **V59-B / Reader 0.4:** 全域予算の下限8.6 CPU年。ただし予算を増やすと下限も増加し、核の過大評価が問題。
- **V60 / Reader 0.5:** 同じ96組を全件較正し、V59/V59-Bと被覆数・評価回数・秒数を比較して予算を更新する作業（結果は未採用）。

**未解決の難所:** 赤道縁の63セルと、層IIの軸に沿う帯には別の計算核が必要です。

## 証拠と採否の約束

1. **探索・較正**、**区間包囲の数値結果**、**A1で採用された研究成果**、**全域の証明**を混同しません。
2. SHA-256一致はファイルの同一性を示しますが、数学的正しさを保証しません。
3. 再現手順、プログラム版、入力、出力、丸め、被覆、独立検査の到達範囲を、可能な限り記録します。
4. Judgeの正式裁定がないものを `CERTIFIED` / `CLOSED` / `PASS` として研究上の結論にしません。
5. 現段階の主矩形の内陸分類は **OPEN** です。
