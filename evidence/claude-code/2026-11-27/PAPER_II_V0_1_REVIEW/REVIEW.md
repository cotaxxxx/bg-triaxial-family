## 2. 論文 I の要約

## 3. §10 の「大域の条件」と、私の符号条件の記録

私の記録（`cotaxxxx/bg-spheroid-family`、枝 `claude/sign-conditions-record-20261126`、`58b42e4`）と矛盾する記述はない。定理 2 の「対があるのは A_i > 0 の側、T_i < 0 の側」は、記録の「対があるのは h_i > 0 ≥ b_i のとき」と同じ向きである。

言い方が弱い所が 3 つある。

| 草稿の言い方 | 記録の条件 | 違い |
|---|---|---|
| no stationary point enters through the third pole | (H3)：球の q_z ≠ 0 の全体で E_z/q_z > 0 | 条件は「第三の極から入らない」より強い。長軸の方向に、面 q_z = 0 の外には停留点がまったくない、という条件である |
| no stationary point is created away from the axes | (H12)：面 q_z = 0 の上で C₁₂ > 0 | 合っている。「面 q_z = 0 の中で」と場所を添えるとよい |
| non-degeneracy along the axes | (HB)：軸の上で E_i(r e_i)/r が r について単調に減る | 条件は非退化より強い。軸の上の対が高々 1 組であること（軸の途中で対が生まれないこと）を与える |

ほかに 2 点。

- 「Persistence … is suggested by uncertified pictures only」：私の側には、保証のない数値の全数調査（1 ≤ 1/y ≤ 4、1 ≤ z ≤ 8 の 1,353 形）がある。「pictures」より「uncertified numerical survey」のほうが実態に近い。
- AI の開示の「Claude Code … formulated the global conditions mentioned in Section 10」は、事実と合っている。この査読を行ったことを、空欄に書き入れてよい。
