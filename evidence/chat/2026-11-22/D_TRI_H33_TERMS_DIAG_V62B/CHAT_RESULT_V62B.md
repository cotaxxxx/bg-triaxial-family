## 2. 分かったこと

1. **一つの次元ではなく、五つの次元の項が同じ大きさで残る。** 深い所では、五つの項がそろって 0.3 前後になる。一次の形の幅はこれらの和なので、符号を決めるには五つすべてを値の 5 分の 1 以下にしなければならない。一つの次元を半分にしても、全体の幅は 5 分の 1 ほどしか減らない。木が五方向に広がるのはこのためである。
2. **浅い所の項は、値の 1 万倍ほどある。** 深さ 0 で q₃ の項は 49,132、s の項は 13,989 で、値は 1.39 である。q₃ を半分にすると、s の項まで 12 分の 1 になる。項の中の「勾配の範囲」は、赤道の近く（q₃ の範囲）で急に大きくなる成分に支配されている。一方で、V62 の点の値は、セルの中で 0.1 も変わらない。**勾配の範囲を箱全体でとる一次の形が、値のなめらかさを大きく見誤っている。**
3. **二次の形は一度も使われなかった。** 計算はしたが、いつも一次の形より広かった。このセルでは、二次の形の計算はすべて無駄になっている（lazy の効きが 1.2 倍にとどまった理由の一つ）。
4. **細長いタイル (3,7) では、角度の幅が値の 44% を占める。** N はいつも上限の 256 で、もう細かくできない。パラメータの項に使える残りは、値の半分ほどしかない。球に近いタイル (0,0) では、角度の幅は 3% で、問題はパラメータの項だけである。

## 3. 何を測るかの見直し（案、Judge 判断の材料）

- **q₃ の偶関数性を使う：** 系は z → −z の鏡映で不変なので、H33 は q₃ について偶関数である。赤道の箱（q₃ ∈ [0, ε]）では、q₃ の一次の項は理論上 0 にできる（展開点を q₃ = 0 に置き、q₃² の項だけを残す）。今の一次の形は、この構造を使っていない。
- **勾配の範囲の取り方を変える：** 勾配を箱全体の範囲でとる代わりに、展開点での勾配（B）と二次の項（C）で包む形がある。この形が今は広すぎる。C の格子 NH を細かくするか、赤道の近くで角度の格子を q₃ に合わせて寄せる。
- **細長いタイルの角度の幅：** N の上限（256）を上げるか、角度の格子の寄せ方（grade）を強める。

どれも、計算の量を増やす前に、表示を問題の構造に合わせる変更である。
