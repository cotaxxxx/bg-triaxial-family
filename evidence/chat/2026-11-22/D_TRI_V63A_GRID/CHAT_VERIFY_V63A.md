## 3. 読み方（計画 §6 のとおり）

計画 §6 は「完走が少なく、残りの箱が減らない → 格子だけでは足りない。V63-B（偶関数性・動く座標）が必要」と決めていた。結果はこちらに当たる。

ただし、次の二点を記録する。

1. **一回の評価の費用：** 評価 1 回は 9 組の平均で 30.3 秒、赤道の H33 の多くで 40〜70 秒だった（ほとんどが N = 512 で、二次の形まで計算）。chat は当初「格子を作る時間が大半で、キャッシュを 4 個で消したので作り直しはさらに多かった」と書いたが、**これは誤りだった可能性が高い**（2026-11-22、Claude Code の指摘で訂正）。V63-A の葉の一覧を順に数えると、新しい格子が要ったのは葉 584 枚のうち 75 回で、評価 2,299 回に対して約 3% である（葉にならなかった箱の評価は記録にないので数えていない）。したがって、Reader 0.7 のテープ方式の効果は、格子を使い回した状態での比（Claude Code の機械で 5〜7 倍）に近くなる見込みである。研究 PC での実測ではない。
2. **V63-A の設定で、木は浅くなり、二次の形が効いた。** 評価が 5〜7 倍速くなれば、同じ予算で評価の回数も 5〜7 倍になり、完走する組が出る見込みはある。これは推測で、確かめていない。
