## 3. 必須の要件

1. **左の面＝論文の地図。** 座標は論文と同じ (y, z)、範囲 R = [1/4, 1] × [1, 7]。四本の弧（Z₁、Z₂、∂₁、∂₂）を台帳の帯から描く。四つの閾値 c_o、b_o、b_p、c_p と交点を表示。対のある側を図 2 と同じく弧に沿った細い帯で示す。R の外は「主張なし」と分かる表示にする。
2. **右の面＝その形の楕円体。** 半軸 (1, y, z)。中心と、極 ±e_y、±e_x を印で示す。形が弧の上（帯の中）にあるとき、定理 2 のどの出来事が起こる場所か（中心か、どの極か、辺 y=1 なら停留円か）を強調表示する。
3. **操作。** 地図の上をクリック・ドラッグして形を選べること（決まった道だけにしない）。あらかじめ用意した道（扁平の辺、扁長の辺、交点を通る道、Z₂ と ∂₂ のあいだを通る道）と再生・停止は残す。
4. **保証の区別を画面に出す。** 少なくとも三種類を色か凡例で分ける：(a) 証明済み（弧が通る帯、端点と交点の区間）、(b) 説明用（帯の中心を結んだ線、対のある側の帯の幅）、(c) 保証のない数値（入れる場合。下の 4 節）。領域ごとの停留点の個数や「両方の対」「なし」のような領域の塗り分けは**しない**（論文が証明していないため。chat の監査用の旧図にはあったが公開図では外した）。
5. **一つの HTML で完結。** 外部の読み込みなし（CDN、アイコン、フォント）。オフラインで開ける。大きさは 5 MB 以下を目標（試作は 14.7 MB）。スマートフォンの幅でも使える。
6. **日本語と英語。** 表示の切り替え。英語が既定。用語は論文と付録 B に合わせる。
7. **再現できる作り方。** 台帳から HTML を作るスクリプトを付ける（`python3 -I`、決定的、入力のコミットと SHA-256 を埋め込む）。画面のどこかに、論文の題名・版・DOI（公開後に記入）・入力のコミットを出す。
8. **ライセンス。** コード MIT、文書 CC BY 4.0（GeoEnclosure の Zenodo 登録と同じ）。Plotly を同梱する場合はそのライセンス表示。

## 4. 任意（できれば）

- 対称な辺・軸の上で、停留点の位置を**保証のない数値**で表示する（軸上の E の一階微分の零点を浮動小数で求めた表を前もって作り、HTML に埋め込む）。入れる場合は「uncertified numerics / 保証のない数値」と常に表示し、弧のあいだで対が存続することを主張しない文を添える。計算は Claude Code の環境で足りる小さなものに限る。研究 PC は使わない。

- v2 の未決箱 8,674 個と、v3 の拡張の重ね表示（§8 の説明用）。
