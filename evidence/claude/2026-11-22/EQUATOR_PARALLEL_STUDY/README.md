## 測ったこと（`band_probe.py`、`band_variation.py`）

E = ⟨k·arccos²γ⟩ の被積分関数の q₃ による n 階微分（n = 2 が H₃₃ の被積分関数）を、2 通りの座標で数値微分し、球面上の積分、絶対値の平均、最大値、角度方向の変動を比べた。

- 通常の座標：球面上の点 ξ を止めて q を動かす。
- 弦の座標：q から見た方向 ω を止めて q を動かす（ξ = q + rω、測度は r²/(ω·ξ) dω）。

点は q = (0.85, 0.22, q₃)、q₃ ∈ {0, 1/64, 1/32}。格子は 2000 × 1000（変動は 4000 × 2000）。式は定義（k = 1 − q·ξ、D = |L(ξ − q)|、B = |L⁻¹ξ|²、γ = k/(D√B)）から書いた。

### L₃ = st = 14.61（s = 2.68、t = 5.45）、q₃ = 1/64

| n | 積分（2 つの座標で一致） | 絶対値の平均：通常 | 弦 | 角度方向の変動の平均：通常 | 弦 |
|---:|---:|---:|---:|---:|---:|
| 2（H₃₃） | +1.4714 | 8.09 | 5.40 | 173 | 112 |
| 3（∂H₃₃/∂q₃） | −0.0662 | 168 | 50.8 | 19,280 | 2,643 |
| 4（∂²H₃₃/∂q₃²） | −4.240 | 16,580 | 1,237 | — | — |

- q₃ = 0 では n = 3 の積分は 0（−3×10⁻¹²）で、偶関数性と合う。
- 「変動 × セルの大きさ」を包囲の幅の目安にすると、n = 3 は通常の座標で N = 256 のとき約 240、N = 512 のとき約 120、弦の座標で約 32、約 16 になる。chat の試験箱での Reader の実測（N = 256 で約 90）と同じ桁である。
- 弦の座標にすると、n = 3 の変動は約 7 分の 1、n = 4 の絶対値の平均は約 13 分の 1 になる。ただし打ち消し合いは残る（n = 3 で、絶対値の平均 51 に対して積分は 0.07）。残るのは、q が球面に近いこと（1 − |q| ≈ 0.12）から来る細かさである。
- 急な所は狭い。変動の半分が、通常の座標では球面の 0.0096%、弦の座標では 0.18% に集まっている。

### q₃ の方向について

H₃₃ は q₃ について偶関数なので、H₃₃(q₃) − H₃₃(0) = ½·q₃²·∂²H₃₃/∂q₃²（途中の点）。q₃ ≤ 1/32 での変化を、4 階微分の被積分関数の**絶対値の平均**で粗く押さえると：

| L₃ | H₃₃(q₃ = 0) | 実際の変化 | 絶対値の平均による上からの見積もり：通常 | 弦 |
|---:|---:|---:|---:|---:|
| 1.69 | 1.222 | 0.004 | 0.035 | 0.011 |
| 6.00 | 1.846 | 0.003 | 0.94 | 0.084 |
| 14.61 | 1.472 | 0.002 | 8.1 | 0.61 |

この 1 点では、弦の座標なら、打ち消し合いを捉えなくても見積もりが H₃₃ の値より小さい。通常の座標では値を超える。

## 限界

保証のない float64 と差分による数値である。点は (s, t) 3 通り × q₃ 3 通りで、q₁・q₂ は 1 通りだけである。「絶対値の平均」は箱の上の上界ではなく、1 点での値である。q₃ = 0 の平面の上で H₃₃ を (s, t, q₁, q₂) の箱について包む問題には触れていない。設計の提案ではない。
