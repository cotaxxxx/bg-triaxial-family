## この条件で測る理由

chat は E3 の72点と20箱すべてで交差を確認した（c157cc6）。2,048面の段階で (0,0) と (1,3) は各18点で正下端、(2,5) と (3,7) は各0/18。後二タイルでは点でも幅は 4.2〜4.6、9.5〜10.4 である。パラメータ幅が既にゼロの点では、パラメータの細分で角度積分の幅を削ることはできない。

72点の位置はすべてセル (27,7,0) にある。E4 の高二タイル六組のうち、同じ位置セルは二組であり、残る四組は (0,23,0)、(4,15,0)、(10,0,0) にある。比較用の20箱はすべて非正下端で、これらは形・位置の幅を持つ箱である。chat が示した六組の未完走の見込みは実行判断に反映する。一方で、現在の八組について、規定時間内にどの位置まで覆えるか、角度と五方向のどれが制約になるかは未測定である。

全八組を既定の角度段階・同じ予算で初回の基準測定にかける。完走できた組だけを選別して流すことはしない。最終段階で符号未決なら、R2 の六つの幅（五パラメータと角度・剰余）と未処理箱を報告する。新たな角度段階、積分式、パラメータ選択則は導入しない。将来変更を提案する場合は実行前に計画を commit して chat の差分監査を受け、核を変える場合は E2・E3 を再実行する。
