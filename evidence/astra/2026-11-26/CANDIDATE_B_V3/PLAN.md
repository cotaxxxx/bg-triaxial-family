## 2. 共有端点と帯

1. $b_p$ の $W=[31/32,1]\times[2,17/8]$ で、$D=(T_y-T_x)/(1-y)$ を二つの既存の $y$ 微分の包囲から作る。$c_p$ では $W=[31/32,1]\times[37/8,77/16]$ に同じ導出を適用する。角度の段階は256、1,024、4,096、精度128ビット。$[D]$ が厳密符号を持つ場合、$y<1$ で共通零を排除する。
2. $b_p$ では $B=[63/64,1]\times[2,17/8]$ に共通帯を試す。端の関数と二量の $y$ 微分を使い、$S=T_y+T_x$ と $D$ から二量の上下の面を包む。両量で下の面が正、上の面が負、横断微分が負、辺根と接続することを要求する。台帳に $S,D$ と二量の面の包囲を残す。[導出 §§1–2](DERIVATION.md)
3. v2 の帯を横断方向だけに広げ、同じ向きの厳密な横断微分を広い帯で確認する。帯の記録順に試し、まだ覆えていない葉と面積が正の重なりがある候補に限る。左右への上乗せ幅の候補 $(y,z)$ は $(1/128,1/32),(1/256,1/64)$、$Z_2$ は先頭に $(1/64,1/16)$ を加える。領域 $R$ の端で切り、最初に成立した候補を使う。微分の段階は64、256、1,024、4,096。
4. 軸の残りは既存の各葉で64、256、1,024セルの直接包囲を試し、符号が読めなければ未決として保存する。軸の未決葉の再分割は行わない。扁平端の5個も帯の拡張とこの直接包囲の対象にする。

## 3. $Z_1,Z_2$ の評価と予算

拡張帯を先に確かめ、被覆済みの葉を追加の求積なしで処理する。残る $Z_1,Z_2$ では、形箱上の直接包囲を16、64、256セルの順に試す。厳密符号が出た段階で止める。直接で符号が定まらない場合、中点は256、1,024、4,096セルで幅 $U-L\le\max(1/256,\max(0,L,-U)/8)$ を目指す。幅を満たす段階で両形微分を256セルずつ求め、平均値形式を直接区間と交差する。符号が未決で中点条件を満たすときに限って、既存の軸選択で二分する。初期の未決葉は深さ・節点名順で配列し、子は末尾に追加する。形の深さ上限18を踏襲する。

$Z_2$ の v2 は帯・接続に約652.6万セルを使い、深さ9–10で本走枠に達した。v3 は帯を追い直す代わりに、保存済みの根と全帯を使い、拡張帯全体で横断微分を一度包む。軽い符号検査の段階を追加し、残る形微分の段階も256セルに固定する。軽量化の実効は、量別の追加セル、拡張帯の成功数、各段階の使用数と未決の深さで読み直す。広い帯の横断微分の余裕や実測短縮率は保証していない。

$\partial_1$ の未消費 8,221,792 セルのうち、300万を $Z_1$、500万を $Z_2$ の追加枠へ配分し、221,792 は余裕に置く。追加枠は $Z_1$ の1,500万と $Z_2$ の1,700万にそれぞれこの配分を足した値で、v2 の原本の再走分は含まない。軸には帯・符号の確認に300万、200万を留保する。各量の形訪問は10万回まで。枠の実行中の移動はしない。

## 4. 交差

$Z_1\cap\partial_2$ の既定窓は $[5/8,21/32]\times[2,5/2]$。両量を八つの固定補助帯で同じ $z_i(y)$ の向きにそろえる。面・横断微分、継ぎ目、傾きの差、両端の順序を確認する。Krawczyk は固定三箱と256、1,024、4,096セルを順に使い、像の真の内部包含、縮小率 $<1$、補助帯の共通支持への像の包含で成立とする。単一の局所一致を示すため、従来の傾き・端点判定と Krawczyk の両方を要求する。すべての区間・箱・試す順序は [固定入力](V3_INPUTS.json) に含める。[導出 §§3–4](DERIVATION.md) · [2d1606d の追補](https://github.com/cotaxxxx/bg-triaxial-family/blob/2d1606dcc31ae8184642b6b9ef8323f0a258f109/evidence/chat/2026-11-26/ASTRA_SCOPE_CANDIDATE_B_V2_20261126.md)

局所の検査は先に記録できる。**全四曲線の被覆と辺の照合がそろうまでは、重なりが零件でも全域の交差判定を保留**する。被覆完了時に零集合の全支持の重なりを再列挙する。拡張帯の零は元の帯に入るので、零集合の支持には元の帯と追加した共通帯を使う。一つの重なり内で、局所証明の支持の辺だけで切った小領域を台帳に記録する。局所支持から外れた部分は少なくとも一方の量の直接包囲の厳密符号を要する。全小領域が説明され、当該対の完了行がある場合だけ、共有端点だけ・内部一件・交差なしのいずれかを記録する。

## 5. 実行時間、記録、範囲

八箱のパイロットに各量2.5万セル、30分。球の $4/3,\pi^2/32$ の包含と、全点・微分の出力を要する。局所検査に120万、最後の交差確認に380万セルを直列で配分する。追加セルの総上限は5,010万。四量の並行相と直列相を合わせて、時間換算は $(2,200万+120万+380万)\max(t_{90,\mathrm{v3}},579905\,\mathrm{ns})$。v2 の実測を使うと約4時間21分、パイロットと検収の余裕を足して約5時間1分。開始時に残り時間を確認し、見積もりが収まらなければ本走を保留する。起動から6時間を上限とし、最後の10分は検査・原本の保全用に確保する。[v2 実測](https://github.com/cotaxxxx/bg-triaxial-family/blob/862220cc03f8044ab770548d865a76ed56fc612c/evidence/dig/2026-11-26/CANDIDATE_B_V2_PC_RESULT/RESULT/summary.json)
