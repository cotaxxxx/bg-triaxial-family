## 1. 採用済みの量と今回測る量

| 零曲線 | 帯 | 採用台帳・対称性から継承 | 新しく包む量 | 数値地図と同じ側を得る符号 |
|---|---:|---|---|---|
| $Z_1$ | 276 | $\nabla_{y,z}A_y\ne0$、$A_x>0$（$c_p$ を除く） | $A_z,\ K_y=E_{yyyy}(0)$ | $+,-$ |
| $Z_2$ | 154 | $\nabla_{y,z}A_x\ne0$、$A_y<0$（$c_p$ を除く） | $A_z,\ K_x=E_{xxxx}(0)$ | $+,-$ |
| $\partial_1$ | 112 | $\nabla_{y,z}T_y\ne0$、軸長差の因子 | $M_y,\ C_{yx},\ C_{yz}$ | $-,+,+$ |
| $\partial_2$ | 72 | $\nabla_{y,z}T_x\ne0$、軸長差の因子 | $M_x,\ C_{xy},\ C_{xz}$ | $-,+,+$ |

新しい量は、中心2項目、極3項目ずつ。$M_i=E_{ii}(e_i^-)$ で、極の横固有値は $T_i=0$ 上で $(\ell_j^2-\ell_i^2)C_{ij}$。符号が予想どおりなら、中心では $A_i>0$ 側、極では $T_i<0$ 側に対があり、短軸の対の Morse 指数は1、中間軸の対は2となる。反対の厳密符号が確かまれば、定理の向き・指数をその符号から読み直す。零を含む区間を条件の破れと数えない。[局所定理と Claude Code との照合](DERIVATION.md)

共有端点 $c_p,b_p$ は、元の辺根箱と v3 の共有端点の記録で固定する。$c_p$ は中心の赤道両方向が退化し、$b_p$ は極の赤道横方向が退化する。これらは既知の例外である。$C_{ij}$ は等軸でも連続な式を用いるので、$b_p$ まで近い帯での検査ができる。$Z_1\cap\partial_2$ は異なる基点の局所条件として検査する。扁平側の $Z_1,\partial_1$ の端と左の辺の $Z_2,\partial_2$ の端も継承帯に含める。

## 2. 入力と実行順

1. v2 `862220c`、v3 `7c6cd7e`、v4 `f58ca0c` の各 RESULT 原本を固定 SHA-256 と照合する。v3 の 4/4 被覆と v4 の六組の関係を読む。v2の `CHART` と v3 の $b_p$ 共通帯から、614帯を組み立てる。各帯の横断微分の参照ID・箱・方向・厳密符号を読み直す。
2. 形の入力はこの帯の長方形だけ。量と帯の参照IDを辞書順に並べ、帯内の検査量は [固定入力](CONDITIONS.json) の順にする。出発点は1,412件。128ビット、角度64→256→1,024セルで、新しい量の包囲が初めて厳密符号を得たところで止める。
3. 零を含む場合は、横断方向の幅は元の帯のままとし、帯の基底軸を中点で二分する。子は待ち列の末尾へ順に追加する。最大深さ4。子箱の $P=0$ のグラフと $P_v$ の厳密符号は元の帯から得る。
4. 最大深さで零を含んだ子箱だけを局所化する。256→1,024→4,096セルで、最初に子箱の基底両端面の $Q$ と経路方向微分 $Q_u-Q_vP_u/P_v$ を読む。厳密な単調性と端の反符号がそろえば一件をその子箱に確定できる。両端が同じ厳密符号で単調なら、子箱の弧上に零はない。いずれも不足なら同じ段で Krawczyk を試す。厳密包含と $q<1$ を両方要求する。$P_v$ は常に既存値を用い、局所化に必要な $P_u$ と Krawczyk の $P(m)$ だけをその帯の内側で追加評価する。
5. 全段で決まらなければ `OPEN`。予算停止の未訪問は `PENDING`。位置が証明できたものは子箱か Krawczyk 像とともに保存する。複数の帯の同一零は重複し得るため、局所記録を足して個数としない。既知の端点例外と普通の符号反転を区別する。

全体の予算は240万セルまたは数値評価7,200秒、単一プロセス。最初の段を全件に使っても112,960セル。240万セルに1セル0.6〜2 msを仮定すると約24〜80分。候補Bの実績は新被積分関数の費用の保証ではない。予算を使い切った場合は未処理の位置を正確な有理端点で再構成する。事前登録時の作業機の確認は、真の MPFR ヘッダでのビルド、球の解析値、人工台帳のみ。四曲線の帯は承認後に Dig が研究PCで評価する。

## 3. 核と監査の手順

採用済みの候補Bのソースは原本とバイト一致。新しい核はそのコピーに別の被積分関数と角度関数の9階係数だけを追加する。旧4量と既存の区間演算、Gauss求積、剰余、角度分割は継承する。生成のバイト差分と各SHA-256を束に含める。検査コードは核と実行ランナーを読み込まず、素区間、元の帯、有理端点から葉・符号、グラフ上の変化、Krawczyk像を読み直す。

計画とコードの固定 → chat 監査 → Judge の別の実行承認 → Dig の実行。得られるのは $R$ 内の四零曲線に沿う局所条件と例外の位置。各領域の全停留点個数・軸外排除は別の主張である。[実行手順](README_RUN.md)
