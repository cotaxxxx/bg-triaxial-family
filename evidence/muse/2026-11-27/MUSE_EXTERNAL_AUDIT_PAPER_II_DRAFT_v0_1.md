## 点ごとの判定

### 1. 定理2の証明（§6）—— 問題なし（軽微な要修正1件を含む）

- **命題 C**：問題なし。E_i(r e_i) = r·H(r², p) の形、H(0,p) = A_i、∂_u H(0,p₀) = B_i（B_i = ∂⁴E/6 の定義と一致）を確認。陰関数定理による u(p) の一意性と、符号 −A_i/B_i から「A_i B_i < 0 の側にちょうど一対」は正しく出る。軸外の除外（E_j = q_j V_j、V_j(0) = A_j ≠ 0）も完全で、z 方向を含む3軸すべてに効いている。共有端点 c_p で仮定 A_j ≠ 0 が崩れることは、定理の側で正しく除外されている。
- **命題 P**：問題なし。Φ(d,p) = E_i((1−d)e_i)、Φ(0,p) = T_i、∂_d Φ(0,p₀) = −N_i の置き方、単調性＋中間値で「T_i N_i > 0 の側に一点だけ」は正しい。軸外の除外（E_j/q_j が E_jj の区間平均で、極での値に tend する）も、内部 Hessian の境界までの連続性があれば成立する。
- **境界正則性**：論理の飛躍なし。D ≥ y·h（R 上では y ≥ 1/4）、k ≤ h（(h−1)² ≤ |q|² と同値で、三角不等式から従う）の2評価から |∂²_q(k f(g))| ≤ C/h の形が出て、1/h が球面上で q について一様に可積分（接触点の近傍で dS ≈ h dh dφ）なので、優収束で連続性が従う、という筋は正しい。d log d の振る舞いの注記は証明には使われておらず（命題 P は連続性だけを使う、と明記されている）、装飾として問題ない。
  - **要修正（軽微）**：この一様評価（q、R 上の形、微分方向のすべてについて一様な C）は命題 P 全体を支える要だが、原稿では1行で置かれている。固定した導出ファイルのどこでこの評価が証明されているかを、原稿から指せるようにしてほしい。評価そのものが導出ファイルに実在するかは原稿の範囲外であり、Astra の照合（依頼書 §3-1）と合わせて最終確認されたい。→ この1点のみ「原稿だけでは判断できない」。
- **横断因子 J_ij**：問題なし。弧の上では ∂²_{q_j}E(e_i) = (ℓ_j² − ℓ_i²) J_ij となり、∂₁ では両因子とも正、∂₂ では ℓ_y² − ℓ_x² < 0、ℓ_z² − ℓ_x² > 0（∂₂ は z = 1 に届かない、端点表と整合）。b_p では y 因子が消えるが、そこは part 3 に切り分けられている。交点 (y*, z*) で命題 C（i=y）と命題 P（i=x）の仮定が同時に満たされることも確認した（y* < 1 < z*、交点は Z₂ の上になく A_x ≠ 0）。

### 2. 定理1の「一本の弧」（§5）—— 問題なし

帯の定義（両面の符号＋横断微分の厳密な符号）から帯ごとに C¹ グラフが1本だけ出ること、重なりでは一意性によりグラフが一致すること、縁の解析で境界根が各 H にちょうど2つであること、の三段は正しい。Step 5 の拡張も正しい：横断方向に延ばした長方形では ∂_c H の符号が単調性を保ち、元の帯の面の符号が外側へ伝播するので、拡張内の零点は元のグラフ上に限る。符号箱（零点なし）と拡張済み長方形（零点は鎖の上のみ）の和集合が R を覆えば、零集合全体が1本の鎖に一致する。覆いの数値的な完全性（タイリング）は台帳側の確認事項で、本監査の範囲外。

### 3. 共有端点での割り算（§5 Step 4）—— 問題なし

H_i(y,z) = P(z) − (1−y) B_i(y,z) の表示は基本定理そのもので、B_i の積分表示も符号まで正しい（s = 1−θ(1−y) の置換で確認）。H₁ − H₂ = (1−y) D、D = B₂ − B₁ を ∂_y 包囲の差で直接囲うので、1−y による割り算は実際には起きていない。窓 W 内で D < 0 が確定すれば y < 1 で両曲線は会わない。共通帯と縁での根の一意性と合わせて、共有点が端点だけであることが出る。論理に問題なし（D の包囲値そのものは台帳照合の担当）。

### 4. 交点の一意性（§5 Step 7）—— 問題なし

Poincaré–Miranda による存在、傾きの積による一意性、の二段は正しくつながっている。g'(z) = −F_z/F_y、h'(y) = −G_y/G_z の陰関数微分、L_g L_h ≤ 0.7105 < 1 の縮小性、2つの共通零点への平均値定理の適用、すべて正しい。横断性も同じ評価から出る：|F_y G_z| ≥ 0.7338 × 0.1595 ≈ 0.117 > |F_z G_y| ≤ 0.3106 × 0.2678 ≈ 0.083 なので Jacobian は消えない。箱 X の外で交わらないことは Step 6 の重なり一覧（4件すべて X の中）で別に示されており、三段の役割分担は明確。Krawczyk は独立した確認として正しく位置づけられている（主証明は Miranda＋傾き、と §8 でも明記）。

### 5. 弧の上での A_x > 0 / A_y < 0（連結性の議論）—— 問題なし

Z₁ の上では A_y − A_x = −A_x、Z₂ の上では A_y − A_x = A_y。c_p の近くで (A_y − A_x)/(1−y) < 0 が確定し、1−y > 0 だから A_y − A_x < 0。Z₁ ∩ Z₂ = {c_p} により A_x は Z₁ ∖ {c_p} で消えず、弧から端点を除いたものは連結なので、符号は c_p 近傍のものが全体に伝播する。Z₂ 側も対称に正しい。
