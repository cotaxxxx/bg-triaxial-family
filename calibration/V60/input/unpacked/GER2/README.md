# GeoEncloseReader 0.5.0

方法論 **GeoEnclosure** のための道具である。区間計算による被覆の台帳を読み、作った人とは別の核で包み直して、符号を確かめる。

扱い：DIAGNOSTIC_ONLY / NOT_EVIDENCE ／ 作成：chat ／ 2026-11-19

## 1. GeoEnclosure（方法論）

GeoEnclosure は、形（Geo）を区間で包み（Enclosure）、符号で構造を決める方法論である。芯は次の四つである。

1. **形に合う表示を選ぶ。** 被積分関数が有界になる見方に置き直してから計算する。弦の表示や、境界のトレースがその例である。
2. **区間で包んで符号を決める。** 標本の値ではなく、有向丸めと相関を保つ包みで、葉ごとに符号を確定させる。
3. **空から再生成し、独立に照合する。** 作った人の核を使わずに、別の実装で同じ符号を確かめる。計画は実行前に固定し、失敗した出力も残す。
4. **解析で残りを閉じる。** 有限個の葉の結果を、単調性、反射対称性、支配収束などの論証で、族全体の結論につなぐ。

研究方程式 REDDS（見→掘→疑→空→再）は、研究の進め方の方法論である。GeoEnclosure は、その中で数学の主張を確かめる方法論にあたる。

GeoEncloseReader は、このうち 3 の「独立に照合する」を担う道具である。

## 2. できること

| コマンド | 内容 |
|---|---|
| `tree LEDGER_GLOB` | 二分木の構造を検査する。親子が半分ずつに分かれているか、終端の有理体積の和が根の体積に一致するかを確かめる。 |
| `verify LEDGER_GLOB PLAN.json OUT.jsonl [--procs N]` | 計画で選んだ終端の葉を、自前の核で包み直す。宣言した符号が出るかを確かめる。 |
| `selftest` | 監査済みの値との回帰を確かめる（約 1 分）。 |

```bash
python -m geoenclosereader selftest
python -m geoenclosereader tree   'final/*.tsv.gz'
python -m geoenclosereader verify 'final/*.tsv.gz' plans/V51_near_boundary.json out.jsonl --procs 2
```

必要なもの：Python 3.11 以上、`python-flint`（0.8.0 で確認）、`mpmath`（1.3.0 で確認）。

## 3. 台帳の形式

列は次のとおりである。

```text
path l0 l1 r0 r1 z0 z1 mode n k alo ahi blo bhi action
```

- **path：** 根は `x`。子は、分けた軸に沿って `0`（下半分）、`1`（上半分）を付け足す。
- **箱の座標：** 整数で、単位は 2⁻²⁰ である。退化した軸は端点が等しい。
- **値（alo〜bhi）：** 整数で、単位は 2⁻³⁶ である。空の箱では `--` になる。
- **action：** 内部の節は `splitl`、`splitr`、`splitz` である。終端は判定の語になる。

照合する組（`verify.TESTS`）は次のとおりである。

| mode:action | 量 | 宣言する符号 | 核 |
|---|---|---|---|
| `V:positive` | E_z | > 0 | (2) |
| `Z:positive` | E_zz | > 0 | 弦 (3)–(4) |
| `E:H_positive` | H ＝ E_yy | > 0 | 弦 (3)、i ＝ y |
| `E:radial_curvature_negative` | E_xx | < 0 | 弦 (3)、i ＝ x |
| `B:H_positive` | H_b | > 0 | (9) |

## 4. 核（`kernels.py`）

式は V48〜V51 で監査した。docstring に全文を書いてある。

- **(2) 勾配のトレース：** E_i ＝ ⟨ξ_i J − L_ii √B u_i K⟩。ここで J ＝ γP − arccos²γ、K ＝ γ²P である。J、K、√B、|u| は閉球で有界である。そのため、接触するセルでは先験的な範囲 γ ∈ [0, 1]、u_z ∈ [−1, 1] に置き換える。
- **(3)–(4) 弦の表示：** E_ii を、方向 e と二つの側 σ ＝ ±1 で表す。重みの和 w₊ ＋ w₋ ＝ 1 を使い、下界は L_max − sup(w_小さい側)(L_max − L_min) で組み合わせる。
- **(9) 境界赤道のトレース：** H_b を、t ∈ [0, 1]、φ ∈ [0, π] で包む。
- **区間の補助（`interval.py`）：** arb は中点と半径の球なので、幅の広い球の二乗や共通部分が 0 未満や NaN になることがある。`sq`、`clip`、`sqrtp`、`acos_safe` は、すべて端点から計算する。
- **P、Q（`series.py`）：** h ＝ (1 − γ)/2 の正項級数を 24 次まで使い、尾部は明示した上界で包む。

## 5. 計画（PLAN.json）の規則

```json
{
  "select": {"E:H_positive": "all", "V:positive": {"weakest": 3, "random": 5}},
  "seed": 51,
  "ladder": {"ez": ["v51b", "fine"], "chord": ["v50", "fine"], "hb": ["v50", "fine"]},
  "depth": 8
}
```

- **実行前に固定する。** 計画とコードの SHA-256 を記録する。結果を見て条件を変えたら、別の計画として残す。
- **格子の段（ladder）：** 宣言した順に試す。各段で、深さ `depth` まで二分する。スコアは dλ、4dρ、4dz の最大である。境界の葉は λ だけを分ける。
- **球の外の子：** 左下の角が球の外（ρ₀² ＋ z₀² ≥ 1）の子の箱は捨てる。作った人の被覆と同じ扱いである。
- **確認の条件：** 残ったすべての子で、宣言した符号が出たときだけ「確認」とする。
- **出力：** 葉ごとに、試した格子、評価の回数、最小値（負の判定では最大値）、作った人の値、秒数を記録する。

格子の名前は次のとおりである。

| 名前 | 核 | 内容 |
|---|---|---|
| `v50` | ez | μ 256 × φ 48。帯 \|μ − z\| < 1/8 で μ を 16 倍にする |
| `v51b` | ez | v50 に加えて、帯の中の φ の最初のセルを 32 倍にする |
| `fine` | ez | μ 1024 × φ 192。帯 1/4 で、μ を 4 倍、φ の k < 16 を 4 倍、k ＝ 0 を 16 倍にする |
| `v50` / `fine` | 弦 | m 512 × ψ 64 ／ m 1024 × ψ 128 |
| `v50` / `fine` | hb | t 512 × φ 64 ／ t 2048 × φ 256 |

## 6. V51 で分かったこと（使う人への注意）

- **λ ≈ 1 の境界の近く：** `v50` と `v51b` の ez では、包みの幅が値を超える。`fine` が必要である。
  - 参照点 (1.0039, 0.95459, 0.25494) の値は E_z ＝ 0.08789 である。下界は、`v51b` で −0.025、`fine` で 0.061 になる。
- **λ ∈ [1.75, 2] の H_b：** 余裕が小さい。`fine` が必要である。
- **球の外の子を捨てないと、** 深さ優先の探索が外側の角へ進み、確認できなくなる。
- **参照の式 4/3 − 8r²/9 は厳密ではない。** これは、球の軸での E_z/z の二項の Taylor 展開である（V51 の訂正 E2、`sphere_axis_check.log`）。正規化の確認には使えるが、下界には使えない。厳密に近い値は `reference.ez_axis_sphere` で計算する。

## 7.1 0.2.0 で加えたもの（V52）

- **λ < 1（扁平）への拡張：** B ＝ |L⁻ᵀξ|² の先験的な範囲を [min(1, ε²), max(1, ε²)] にした（`kernels.b_range`）。λ の箱の端は厳密な有理数 1/l₀²、1/l₁² で取る。λ ≥ 1 の箱では 0.1.0 と同じ値になる（selftest で確認）。
- **軸の上の一次元の核：** `ez_axis_bound`（(2)、ρ ＝ 0）と `ezz_axis_bound`（弦の (3)–(4)、i ＝ z、ρ ＝ 0）。軸の上では被積分関数が方位によらないので、一次元の細かい分割で、二次元の格子よりずっと狭く包める。
- **扁平の D5 の台帳への接続（`oblate_d5.py`）：** (d ＝ 1 − r, τ, λ) の箱を、子午面の写像 ρ ＝ r(1 − τ²)/(1 + τ²)、z ＝ 2rτ/(1 + τ²) で (ρ, z) の包みの箱に写す。そのうえで H ＝ E_yy > 0 を確かめ、二分は極座標で行う。
- **selftest：** 扁平の三項目を加えた。λ ＝ 0.4 と 0.5 での E_zz(0) の値（D-OB の H_axis を含む）と、λ ＝ 0.5 で軸の上の根が 0.75〜0.81 の間にあることである。

**分かった注意点：** λ_c のすぐ上（λ ≈ 0.42〜0.43）では、E_z は 2×10⁻³ ほどしかない。これは O(1) の項どうしの相殺で、λ の幅 1/800 の球の演算だけで約 3×10⁻³ を失う。点の λ なら確かめられる。帯の全体で示すには、λ についての平均値形式か、作った人の C0 のような三階微分による論法が要る。

## 7.2 0.3.0 で加えたもの（V57、三軸）

- **三軸の核（`tri.py`、`tri2.py`）：** L ＝ diag(1, s, st)。中心の h_i（八分体）、極の全勾配のトレース b_i ＝ E_i(e_i)（極を中心にした地図で、特異な因子がない）、扁長の辺の赤道円板での τ ＝ (T₁₁ − T₂₂)(re₁) とその二階微分 τ″。
- **平均値形式による二次の包み（`tri2.py`、`dual.py`）：** 区間の双対数で、セルの上の勾配を包む。セルの中心の値に、重みの一次モーメントと |x − x_c| のモーメントを組み合わせる。幅は角度の分割に対して 1/N² で縮む（0.2.x の値域の包みは 1/N）。形の箱（または (t, r) の箱）は、中心の値と、箱の上の形の勾配で包む。
- **binary64 の外向き丸め（`fiv.py`）：** numpy の四則と平方根は正しく丸められるので、各演算の端を 1 ulp だけ外へ動かす。三角関数・π・級数の係数は libm から取らず、mpmath か厳密な有理数から外向きに丸める。和は math.fsum を使う。
- **級数：** P、P′、P″、P‴、Q、F ＝ arccos² を h ＝ (1 − g)/2 の正の級数（60 次）と明示的な尾で包む。g は [0, 1] に入れる。
- **selftest：** `selftest_tri.py`、`selftest_tri2.py`。級数を mpmath と、核を chat の非区間の Gauss–Legendre（384 点）と比べる。V57 の時点で全項目が通る。

**分かった注意点：** 細長い形（st が 19 に近い）での h₃ は、一様な角度の分割では幅が大きい（N ＝ 64 で ±5）。赤道の近くを細かくする分割が要る。

## 7.3 0.4.0 で加えたもの（V58〜V59、三軸の一般の点）

- **一般の点の核（`tri3.py`）：** 球面全体の地図で E3、T12、H33 を包む。パラメータは (s, t, q₁, q₂, q₃) の箱で、角度は平均値形式（二次）、パラメータは箱の上の勾配（一次）で包む。
- **接触セル：** D² の下界が (4/N)² 以下のセルは、先験的な上界にセルの測度を掛けて扱う。
- **段階的な θ 格子：** arccos(q₃) のまわりに細かくする。強さは L₃ で決める。

**訂正 E3（0.5.0 で発見）：** 0.4.0 は、箱の中心が球の外にあっても、その中心でパラメータの平均値形式を作っていた。球の外では g の [0, 1] への切り詰めが真の値を変えるので、その箱の包みは正しくない。影響は較正（V58、V59、V59-B）の縁の箱の数だけである。V59 の 96 組では、初めの箱で 8 組がこれに当たる。採用済みの結果は tri3 を使っていない。

## 7.4 0.5.0 で加えたもの（V60）

- **二階の jet（`jet.py`）：** 区間の値・勾配・選んだヘッセ行列の成分を運ぶ。零の成分は持たない。
- **パラメータの二次の包み（`tri4.py`）：** 展開点 p₀（箱 ∩ 球の点）でのテイラー展開に、積分形の剰余を付ける。(A) p₀ での値（角度の平均値形式）、(B) p₀ での勾配（∂ⱼf の角度の平均値形式。jet で ∂_a∂ⱼf を包む）、(C) 箱の上のヘッセ行列（粗い格子 N_H ＝ N/2 のセル × 箱の値域）を使う。同時に、一次の形（0.4.0 の形に E3 の修正を加え、勾配はセルの和を先に取る）も計算し、二つの包みの共通部分を返す。共通部分が空なら INCONSISTENT として止まる。
- **展開点：** 箱の中心が閉球にあればそれを使う。なければ、原点にいちばん近い箱の点へ半分ずつ寄せる。
- **効果（V59-B の D1 の箱、N ＝ 256）：** 0.4.0 では 1/16 に縮めてはじめて正に決まった箱が、1/8 で決まる（[0.75, 1.81]）。1/16 での幅は 1.8 から 0.38 になる。大きな箱では二次の形のほうが広く、そこは共通部分が一次の形を残す。
- **selftest：** `selftest_tri4.py`（jet の値・勾配・ヘッセ行列を mpmath の微分と比べる。点の箱、小さな箱の 6 点の参照値を含むか。中心が球の外にある縁の箱を含む）。0.5.0 で全項目が通る。

**分かった注意点：** (C) のヘッセ行列は、粗いセルの上の値域で取る（角度について一次）。N_H を 2 倍にすると幅はほぼ半分になる（V60 の試験：N_H ＝ 32、64、128 で 986、299、160）。剰余は半径の 2 乗で効くので、小さな箱では効きが小さい。大きな箱では、二次の形が一次より悪くなる。

## 8. 限界

- **扱える族：** 回転対称な族（λ > 0）、三軸の中心・極・扁長の辺の赤道円板（0.3.0）、三軸の一般の点（0.4.0、0.5.0）。接触セルのある箱は一次の形だけで包む。
- **包みの精度：** 0.2.x の核は格子のセルでの値域で取る。0.3.0 の三軸の核は平均値形式（二次）である。
- **確かめる範囲：** 確かめるのは、選んだ葉の符号だけである。被覆全体の正しさは、作った人の検査器の再生と `tree` の検査、それにこの抜き取りを合わせて判断する。
